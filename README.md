# willwhi.github.io

个人 GitHub Pages 主页，使用纯 HTML、CSS 和 JavaScript 构建。

## 本地预览

```powershell
C:\Program Files\PowerShell\7\pwsh.exe -Command "python -m http.server 4173"
```

然后打开 http://localhost:4173。

## 发布到 GitHub Pages

仓库名称需要是 `willwhi.github.io`，将本目录内容推送到 `main` 分支，然后在 GitHub 的 Settings → Pages 中选择 GitHub Actions 或 `main` 分支部署。
